# Infinit Advisory — UI Kit

A recreation of **Infinit Advisory**: the enterprise-architecture, platform-strategy and data/AI practice. More structured and table-like than Studio. Dark canvas as the default, deep-blue body, accent blue used as a system color rather than as ornament.

## Files

| File | What it is |
|---|---|
| `index.html` | Click-thru: Home → Services → Methodology → Leadership → Contact |
| `Nav.jsx` | Top nav, dark, "advisory" sub-mark |
| `Hero.jsx` | "Strategic & Digital Architecture / designed to scale." hero |
| `Problem.jsx` | The deck's "Most companies don't lack tools..." statement block |
| `Services.jsx` | Architecture / Platform Strategy / Data & AI triplet |
| `Methodology.jsx` | The 5-step bar: Understand → Map → Structure → Decide → Scale |
| `Leadership.jsx` | Founder card with executive experience pulled from the deck |
| `tokens.css` | Imports root tokens; switches the default theme to dark |

## Notes

- Copy is taken verbatim from the founder deck wherever possible (slides 14–24).
- Footer + Nav are visually paired with Studio; only the sub-mark word and accent treatment change.
- Leadership content is the **real** founder bio from the deck (Francesc Callejas). Update as the team grows.
