# Web a medida o WordPress: ¿qué le conviene a una empresa industrial?

**Respuesta corta:** para una empresa industrial o B2B que quiere una web que venda en varios mercados, que se mantenga fácilmente y que encuentren Google y los asistentes de IA, una web a medida — ligera y con un backoffice sencillo si hace falta — suele salir mejor a medio plazo que una plantilla de WordPress o Webflow. Una web a medida puede estar lista en un mes (dos si es compleja) y cuesta desde unos 10 k€ según el tamaño de la empresa.

WordPress y Webflow son herramientas fantásticas para muchos proyectos. Pero en empresas industriales vemos siempre el mismo patrón: la plantilla funciona el primer año y, a partir de ahí, cada cambio cuesta más.

## El problema de las plantillas

- **Nunca acaban de ajustarse.** La plantilla se pensó para otra empresa. Vuestro catálogo, vuestros sectores o vuestras certificaciones acaban forzados dentro de una estructura ajena.
- **Cuesta mucho tocarlas.** Plugins, actualizaciones y dependencias: un cambio pequeño puede romper otra cosa.
- **Pesan.** Muchas plantillas cargan mucho más código del que necesitáis. Una web lenta pierde visitas y posiciones en Google.

## Qué ganáis con una web a medida

- **Hecha para vuestra empresa:** la estructura responde a cómo vendéis — por sectores, por productos, por mercados.
- **Rápida y ligera:** solo el código necesario.
- **Mantenimiento sencillo:** pensada desde el primer día para que actualizarla no sea un problema.
- **Backoffice a medida cuando hace falta:** para gestionar productos, noticias o documentos de forma mucho más rápida que un panel genérico.
- **Preparada para Google y la IA (GEO):** datos estructurados, una página para cada idioma, preguntas frecuentes reales y un resumen para los asistentes de IA. Es exactamente lo que hemos hecho en nuestra propia web.

## Plazos y costes orientativos

| Tamaño de la empresa | Web, SEO y GEO | Plazo |
|---|---|---|
| 1–10 M€ | ~10 k€ | 1 mes |
| 10–50 M€ | 12–18 k€ | 1–2 meses |
| 50–200 M€ | desde 20 k€ | 1–2 meses |

Si la web incluye un backoffice complejo, el plazo se alarga. Son cifras orientativas: si vuestro presupuesto es otro, adaptamos el alcance.

## Cómo lo hacemos

1. **Estrategia y arquitectura:** qué debe hacer la web, para quién y en qué idiomas.
2. **UX/UI y diseño:** os enseñamos el progreso en sesiones periódicas.
3. **Programación a medida, SEO y GEO.**
4. **Lanzamiento:** y, si queréis, un plan de lanzamiento con vídeo.

## Preguntas frecuentes

**¿Y si ya tenemos WordPress?** No hace falta tirarlo todo el primer día. Primero miramos qué funciona y qué no, y decidimos juntos.

**¿Quién mantiene la web después?** Está pensada para que el mantenimiento sea sencillo, y con un backoffice a medida vuestro equipo puede actualizar los contenidos.
