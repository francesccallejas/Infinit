# INFINIT© website — working conventions

## Architecture (since the 2026 redesign)
Static site generated by a dependency-free Node script. **Never edit the generated HTML by hand.**

| What | Where |
|---|---|
| Page templates (Home, Studio, cases) | `.site/pages/*.mjs` |
| Shared chrome: `<head>`/SEO, dock, menu, footer | `.site/layout.mjs` |
| UI + Home + Studio copy (EN / CA / ES) | `.site/i18n.mjs` (case copy lives in each case module) |
| Services, projects, client logos | `.site/data.mjs` |
| Styles | `assets/site/base.css` (all pages) · `home.css` · `inner.css` (Studio + cases) · `studio.css` |
| Behaviour (motion, dock, menu, quick look, carousels…) | `assets/site/site.js` |
| Fonts (self-hosted) | `assets/site/fonts/` — Satoshi variable + Geist 500/900 (wordmark only) |
| Design reference | `.handoff/design_handoff_infinit_website/` (README + prototype source) |

**Workflow:** edit `.site/…` or `assets/site/…` → `node .site/build.mjs` → commit the source **and** the generated files.
The build writes `/en/`, `/ca/`, `/es/` pages, the language gateway `/index.html`, `404.html`, `sitemap.xml`, `robots.txt`, `_redirects`, `_headers`, and cache-busts CSS/JS with a content hash (`?v=…`) automatically.
`node .site/og.mjs` regenerates Open Graph images + apple-touch-icon (needs `sharp`, one-off).

## i18n
- Routes `/en/ /ca/ /es/` (same slugs), `hreflang` + canonical on every page, sitemap with alternates.
- `/` is a gateway: saved choice (`localStorage inf-lang`) → browser language → English.
- Language links (menu + footer) persist the choice.
- New copy: add it in **all three languages**. CA/ES headlines run longer — check they don't break the layout.

## Deployment
- GitHub `main` → Cloudflare Pages → **www.weareinfinit.com** (auto-deploys on push to `main`, no build step: the repo root is served as-is).
- Domain at **GoDaddy** (DNS there): `www` is a CNAME to `infinit-ede.pages.dev`; the bare domain forwards to www. Canonicals, sitemap and `llms.txt` use `SITE` = https://www.weareinfinit.com (`.site/lib.mjs`).
- **Dot-prefixed folders are NOT deployed** (`.site`, `.handoff`, `.lab`, `.archive`, `.chats`).
- Old URLs (`/studio.html`, `/work/bunnker/`, `/work/relats/`) 301 to `/en/…` via `_redirects`.
- The previous site lives in `.archive/site-v1/` and the old design systems in `.archive/design-system-v01|v02/` — obsolete, don't use.

## Design tokens (source of truth: `assets/site/base.css` `:root`, from the handoff)
- Two families only: **Satoshi** (all text) and **Geist 900** (the `INFINIT©` wordmark only, © in Geist 500). Instrument Serif / IBM Plex Mono are superseded.
- Light ground `--bg` oklch(.975 .002 85) · ink `--t4` · secondary `--t3` · grey emphasis `--t2 #9A999A` (`.em`: grey sentence, key words in `<b>` full ink — display sizes only; small text uses `--t3` for contrast).
- Dark ground `.dark`: `--d0` … `--d4`.
- Service hues (used subtly — dots, tints, card backs, the colour line): Strategy 165 · Brand 255 · Digital 285 · Product 30 · Content 88.
- Colour line ("One colour"): 3px, one service colour at a time (mint → blue → lilac → coral → ochre), 20s loop (`@keyframes ln1`), synced across pages via `--lnd` set in <head>. Used on hero bottoms, the light→dark transition and the preloader bar. The SVG favicon swaps to the current colour on load (`/favicon-<colour>.svg`). The big email hover sweep stays multicolour.
- Easing: in-out `cubic-bezier(.7,0,.2,1)` · out `cubic-bezier(.2,.7,.2,1)`.
- `--pad: clamp(20px,3vw,44px)`. No horizontal overflow (`overflow-x: clip`).

## Behaviour to preserve
- Floating dock (bottom centre): auto-contrast over `.dark`, hides at the footer, scrollspy dot. Mobile: wordmark · burger · Let's talk; burger → coral X; fullscreen menu with circular clip reveal.
- Home: preloader once per session, hero cross-fade, drag carousel ⇄ grid, scroll-scrubbed approach, flip service cards, Quick look bento overlay, giant copyable email.
- Accessibility: visible focus, focus trap + `aria-expanded` on menu and Quick look, flip cards by keyboard/tap, alt text, `prefers-reduced-motion` (no preloader / smooth scroll, instant reveals).
- Only one `id="contact"` (Home/Studio contact block). The footer is `#ft`.
